# SAMStat long-read fixtures

Generated by `tests/tools/make_longread_fixtures.py` (seed 240); do not edit by hand. Regenerate with `uv run python tests/tools/make_longread_fixtures.py` from the repository root (BAM files need htslib `test/test_view`, see the script header).

Every expected value below comes from the generator's own ground truth (the true alignment of each simulated read) and from the definitions in `docs/plan-v2.4/standard-plots.md` section 3. None was read from a samstat run. Where a number can be checked by hand, the derivation is shown.

## Conventions

- Keys are the `summary` keys of `standard-plots.md` section 7. Under the transitional `v2.` prefix (waves 3-4) they live in `v2.summary.*`.
- Statistics are primary-only: secondary (0x100) and supplementary (0x800) records are excluded; a record with both flags counts as secondary.
- Read length is the full `l_qseq`, soft-clipped bases included. A record with `SEQ *` has length 0.
- `n50_exact` and `median_length_exact` are the exact values (median: lower median). `n50` and `median_length` are the lower edge of the storage length bin containing them (exact below 1000 bp, about +1% steps above; section 3.1). Compare samstat output to the binned value exactly, or to the exact value within 1%.
- `mean_q` is `-10 log10(mean of 10^(-q/10))` over all bases with a quality, clipped bases included. `mean_phred_arithmetic` is the plain mean of the Phred values, for contrast.
- `median_identity` is the lower edge (percent) of the identity bin (0.1% wide) holding the lower median read; `median_identity_exact` is the exact lower-median identity. Identity is `(M - X) / (M + I_events + D_events)` (section 3.4); samstat should agree within 0.5 percentage points.
- `mismatch_bases`, `insertion_events`, `deletion_events`, `aligned_bases`, `aligned_md_bases` are the sums of the `relative` position arrays `mismatches`, `insertions`, `deletions`, `aligned`, `aligned_md` over all MAPQ classes (the relative axis loses nothing; the absolute axis stops at position 1000). Position axes cover the aligned part of the read only.
- `clipped_bases` is the number of soft-clipped bases of mapped primary reads.
- SEQ and QUAL are written as stored in the file (reference orientation); flag 16 marks reverse-strand reads but SEQ is not reverse-complemented by the generator, so ground truth never depends on strand.

## Size and scope notes

The package asked for about 40 reads of 500 bp to 30 kb in `ont_like`, a 15 kb `hifi_like` and a 1-50 kb `long.fq`. SAM and FASTQ are uncompressed text (about 2.4 bytes per base for ONT-like reads) and each file is capped at 100 KB (300 KB in total), so the committed files are scaled down: `ont_like` has 24 reads of 500 bp to 3.5 kb, `hifi_like` 4 reads of 3.0 to 6.0 kb, `long.fq` 12 reads of 1 bp to 5 kb. `ont_like.bam` additionally holds one 52.5 kb read. The 1 Mb case is built by CMake at test time (`tests/cmake/run_ultralong.cmake`), and `make_longread_fixtures.py --reads N` makes large files for `tests/perf/bench.sh`.

## Checking the files

`samtools quickcheck` and `samtools view` parse every SAM and BAM here. `samtools stats` and `samtools view -q` agree with the read, base, mapped, unmapped and MAPQ counts above for `ont_like.sam`, `supp_chain.sam` and `mapq255.sam` (a manual cross-check, not a test). Every MD tag, CIGAR, NM and SEQ of each SAM was also checked for mutual consistency (CIGAR query length equals SEQ length, MD matches and deletions equal the CIGAR, NM equals mismatches plus indel bases, each MD mismatch differs from the read base).
